# 07 — Internationalization

Two independent axes — do not conflate them:

| Axis | Values (v1.0) | Owner |
|---|---|---|
| **UI language** | en · vi · ja | `src/locales/` + i18next |
| **Quote locale** | en · vi · ja · zh-Hans · zh-Hant · ko | `data/quotes/` + region routing |

A Japanese-UI user can browse Vietnamese proverbs and vice versa.

## 1. UI i18n (i18next)

- Namespaces: `common`, `settings`, `media`, `updater`, `legal`, `errors`.
- Key style: `media.err.videoSize` — lowercase dot paths; **English file is the
  source of truth**; `vi`/`ja` must mirror keys 1:1 (CI script diffs key sets).
- Interpolation via i18next `{{cap}}`; no string concatenation in components.
- vi/ja have no plural forms — keep `_one/_other` only in `en` where needed.
- Language detection: saved setting → `navigator.language` → `en`.

## 2. Quote locales & routing

`data/quotes/index.json` maps regions → locale files (doc 04 §2). v1.0 routing:

| Region | Locale |
|---|---|
| VN | vi |
| JP | ja |
| CN, SG(zh) | zh-Hans |
| TW, HK, MO | zh-Hant |
| KR | ko |
| US, GB, AU, … (+ every unrouted region) | en |

Quotes render in their original `lang`; the optional bilingual line uses
`translations[uiLanguage] ?? translations.en`.

## 3. Adding a locale (checklist — used every rollout wave)

1. `data/quotes/<code>.json` (schema-valid, ≥ 50 quotes to launch).
2. Register in `index.json` with `dir`, `fontKey`, `regions`.
3. Add/extend font + rerun `subset-fonts` (§5); add `fontKey` CSS stack.
4. Holiday overrides for the new countries if needed.
5. Calendar row (§4) if the region has one; else Gregorian only.
6. Fixture + snapshot test: selection & attribution over the new pool.
7. Roadmap/decision-log entry (doc 15).

## 5. Font subsetting pipeline (build-time)

Because every rendered string is static (bundled data + UI locales), fonts can
be subset to the exact glyph set:

```
scripts/subset-fonts.ts
  glyphs(locale) = chars(data/quotes/<locale>.json)
                 ∪ chars(src/locales/**)  ∪ digits ∪ punctuation ∪ "…—–·"
  for each fontKey → subset-font(source.ttf, glyphs) → public/fonts/<key>.woff2
```

Effect: Noto Serif JP/SC/TC drop from multi-MB to a few hundred KB each.
CI re-runs the script whenever `data/**` or `src/locales/**` change and fails
if committed woff2 files are stale (hash check).

## 6. RTL readiness (prep now, ship in v1.6–1.8)

- Layout uses **CSS logical properties only** (Tailwind 4.2+ logical
  utilities: `ps-*`, `inset-s-*`, `mbs-*`…) — enforced by lint rule banning
  the physical `left/right` margin/padding utilities in `src/`.
- The quote block sets `dir` + `lang` from the quote record, independent of
  the UI direction; UI flips only when an RTL UI language ships (not planned).
- Arabic wave adds `fontKey: serif-ar` (Noto Naskh Arabic) + `dir: "rtl"` in
  the locale index; nothing else should need touching — that is the test.

## 7. Formatting rules

Dates/times via `Intl.DateTimeFormat(uiLocale)`; file sizes via
`Intl.NumberFormat` + binary MB; country names via `Intl.DisplayNames`;
never hand-format any of these.
