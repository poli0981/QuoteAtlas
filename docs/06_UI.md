# 06 — UI Specification

Design language: quiet, typographic, content-first. One screen; everything
else is overlays. Dark and light themes derive from the background choice.

## 1. Main screen

```
┌──────────────────────────────────────────────────────────────┐
│  Thứ Hai, 6 tháng 7 · 00:20:25                      [🌐 VN ▾] │
│  Âm lịch: ngày 22 tháng Năm, Bính Ngọ                         │
│                                                              │
│                                                              │
│            Có công mài sắt, có ngày nên kim.                 │
│                                                              │
│                              — Tục ngữ Việt Nam              │
│                                                              │
│                                                              │
│   ‹        ♡        ⧉        ⛶        ⚙                      │
└──────────────────────────────────────────────────────────────┘
    prev   favorite  copy   fullscreen  settings   (auto-hide after 3 s)
```

- Quote block: horizontally & vertically centered, `max-width: 34ch`,
  text-wrap balance.
- Clock block top-left (locale date + live `HH:mm:ss`); second line = regional
  calendar (doc 07 §4), hidden where not applicable.
- Region picker top-right: flag/ISO code, opens searchable list; shows the
  active fallback ("Showing English — no pool for IS yet").
- Bottom toolbar fades out after 3 s idle (and instantly in fullscreen);
  any pointer/keyboard activity restores it. Cursor auto-hides in fullscreen.
- Bilingual mode (setting): translation rendered under the original at 0.6 em,
  70 % opacity.

## 2. Typography

| Token | Value |
|---|---|
| Quote ≤ 80 chars | `clamp(1.9rem, 5vw, 3.6rem)` |
| Quote 81–200 | `clamp(1.4rem, 3.6vw, 2.6rem)` |
| Quote > 200 | `clamp(1.1rem, 2.8vw, 1.9rem)` |
| Attribution | `0.55em` of quote size, letter-spacing 0.02em |
| Clock line 1 / 2 | 1rem / 0.85rem, 80 % / 60 % opacity |
| Fonts | quote = `fontKey` from locale index (doc 04 §2); UI = Be Vietnam Pro |

Quote text may use `text-shadow-md/lg` (Tailwind 4.1+) automatically when a
media background is active.

## 3. Backgrounds panel (inside Settings → Background)

Modes (radio): **Color** (picker + opacity slider — opacity <100 % = the
"transparent" mode; on desktop this reveals the transparent window) ·
**Gradient** (2–3 stops, angle) · **Image** · **Video** · **Slideshow**.

Media library grid: thumbnails, per-item size badge, delete; header shows
`used / cap` count and a storage meter (`storage.estimate()` on web).
Add-button flow and all caps: doc 03 §4 + doc 04 §7.

Slideshow controls: item multi-select from library, interval 5–300 s,
transition (crossfade | fade-to-black), shuffle toggle, Ken Burns toggle
(images only).

Text styling: font color, scrim 0–80 %, text-shadow on/off. Contrast hint per
doc 05 §8 — advisory chip "Low contrast — raise scrim?".

## 4. Oversize-image dialog (exact contract)

Title: *"Ảnh vượt giới hạn {cap} MB"* / *"Image exceeds the {cap} MB limit"*
Body: current size, class (1080p/4K), what auto-compress will do (WebP,
resize to {edge}px).
Buttons: **(1) Tôi tự giảm và tải lại** (secondary) · **(2) Nén tự động**
(primary). Progress state → before/after size comparison → Keep / Discard.

## 5. Rejection toasts (video & library)

| Case | Copy (i18n key) |
|---|---|
| Video > 3:00 | `media.err.duration` — "Video dài quá 3 phút — hãy cắt bớt (gợi ý: LosslessCut)." |
| Video > cap MB | `media.err.videoSize` — "…hãy nén lại (HandBrake/ffmpeg, AV1/VP9 cho 4K)." |
| Video > 4K | `media.err.resolution` |
| Library full | `media.err.libraryFull` — "Thư viện đã đạt {cap} mục — xóa bớt để thêm mới." |
| Quota (web) | `media.err.quota` — opens storage meter |

## 6. Region picker

Search-as-you-type list of countries (localized names via
`Intl.DisplayNames`), grouped: *Detected* · *Has native pool* · *All*.
Selecting a country with no pool immediately shows the fallback banner. A
"Reset to auto" row restores detection.

## 7. Attribution line rendering

Templates and field collapsing: doc 04 §5. Links are underlined-on-hover,
open externally (adapter). Touch targets ≥ 44 px on mobile. Long attributions
wrap to two lines max, then truncate the *actor/publisher* segment first.

## 8. Fullscreen & desktop behaviors

F11 / ⛶ toggles. Desktop: `setFullscreen(true)` — the OS hides − ▢ ×
(requirement satisfied natively; no custom chrome). Esc exits. While
fullscreen: toolbar hidden, cursor auto-hide 3 s, optional auto-rotate mode
suggestion on first use. Windowed: native decorations, size/position restored
by `window-state`, single-instance focuses the existing window.

## 9. Error & offline surfaces

App-level pages (SPA states, each with a themed quote for tone):

| State | Trigger | Key copy id |
|---|---|---|
| 404 | unknown route / missing asset | `err.404` "Trang này lạc lối rồi." + Home |
| 403 | host-level (rare) | `err.403` |
| 429 | host-level rate limit | `err.429` |
| 5xx | host-level | `err.5xx` |
| Offline (first visit) | SW not yet cached | `err.offline` + retry |

Update-check dialogs (codes from doc 03 §5):

| Code | Copy |
|---|---|
| `E_UPDATE_OFFLINE` | "Không có kết nối mạng. Sẽ thử lại sau." |
| `E_UPDATE_RATELIMIT` | "GitHub đang giới hạn truy cập. Thử lại sau {min} phút." |
| `E_UPDATE_NO_RELEASE` | "Chưa có bản phát hành nào." |
| `E_UPDATE_SERVER` | "GitHub đang gặp sự cố. Vui lòng thử lại sau." |
| `E_UPDATE_BADSIG` | "Gói cập nhật không hợp lệ — đã hủy vì lý do an toàn." |
| other | generic + code + [Báo lỗi] |

Note: HTTP **419 is not a standard status** (Laravel-specific); the spec uses
429 everywhere.

## 10. Legal gate (blocking, first run/visit)

Modal, no dismiss besides the button; content scrollable:

```
◆ QuoteAtlas
Trước khi tiếp tục / Before you continue
• Giấy phép mã nguồn: GPL-3.0        → link GitHub LICENSE
• EULA · Disclaimer · Privacy Policy → links (legal/*.md on GitHub)
• Third-party notices · Attributions → links
Ngôn ngữ giao diện: [EN ▾]
              [ Đồng ý & tiếp tục / Agree & continue ]
```

Stores `{ consentVersion: LEGAL_VERSION, at }`. Bumping `LEGAL_VERSION`
re-gates. The gate is also reachable later via Settings → About.

## 11. Settings inventory

General: UI language (EN/VI/JA) · region override · quote mode
(per-load/daily/rotate + interval) · bilingual display · 12/24 h · regional
calendar on/off. Background: §3. Updates (desktop/Android): auto-check toggle
· Check now. Data: favorites list · export/import settings · clear media.
About: version, license links, legal gate reopen, **Report bug**, Export logs.

## 12. Motion & accessibility

Quote change: 450 ms crossfade + per-word stagger (Motion, 18 ms/word, cap
600 ms). Background slideshow: 800 ms crossfade. All non-essential motion
gated behind `prefers-reduced-motion: no-preference`. Focus rings always
visible; full keyboard path (arrows = prev/next, F = favorite, C = copy,
F11 = fullscreen); `aria-live="polite"` on the quote block; contrast advisory
per doc 05 §8.
