# 13 — Release & Publishing

Distribution channels: **GitHub Releases** (desktop + Android) and
**Cloudflare Pages** (web). No stores in v1.x (doc 08 §7).

## 1. Release artifact set (every `v*` tag)

| Artifact | Notes |
|---|---|
| `QuoteAtlas-Setup-x64.exe` | NSIS; unsigned in v1 (SmartScreen note in README) |
| `QuoteAtlas_{v}_universal.dmg` | macOS aarch64+x64 |
| `QuoteAtlas_{v}_amd64.AppImage` / `.deb` / `.rpm` | Linux |
| `quoteatlas-v{v}-android-arm64.apk` | primary Android artifact (stable name) |
| `quoteatlas-v{v}-android-universal.apk` | optional, larger |
| `latest.json` + per-platform `*.sig` | tauri-plugin-updater manifest, minisign-signed |
| `SHA256SUMS` + `SHA256SUMS.asc` | all files above; GPG detached signature |

## 2. Keys (⚠️ one-time human setup; private material never enters the repo)

| Key | Generate | Store |
|---|---|---|
| Minisign updater keypair | `npm run tauri signer generate` | private → CI secret + offline backup; **public key → `tauri.conf.json` (committed)**. Losing it strands desktop auto-updates → treat like the GPG key |
| Android keystore | `keytool -genkeypair -keyalg RSA -keysize 4096 -validity 10000` | base64 → CI secret + two offline backups. Losing it breaks APK upgrade-in-place for all users |
| GPG | existing SkullMute release key | fingerprint published in README + SECURITY.md |

## 3. `latest.json` (generated by the bundler; shape for reference)

```jsonc
{ "version": "1.0.1",
  "notes": "…", "pub_date": "2026-…",
  "platforms": {
    "windows-x86_64":  { "signature": "…", "url": "https://github.com/poli0981/quoteatlas/releases/download/v1.0.1/…" },
    "darwin-universal": { … }, "linux-x86_64": { … } } }
```

Updater endpoint in `tauri.conf.json` points at
`…/releases/latest/download/latest.json` — no separate hosting needed.

## 4. Versioning & changelog

Semver per doc 05 §9 (`data:`-only → patch). Single source of version:
`package.json` → sync script writes `tauri.conf.json` + `Cargo.toml` at
release. `CHANGELOG.md` keep-a-changelog style; the `v{x}` section body
becomes the GitHub release notes (and what the Android dialog shows —
write it for end users, EN first, VI second).

## 5. Release procedure

1. `main` green; bump version (`npm run release:prep` — sync + changelog
   scaffold).
2. Tag `v{x}` → push → `release.yml` runs (doc 12 §3) → draft release
   assembled → auto-published on success.
3. Post-publish smoke: desktop auto-update from previous version on one OS;
   Android dialog shows the new version + correct SHA-256; web deploy live;
   `latest.json` reachable.
4. Announce (optional): existing cross-platform notify tooling.

## 6. Full manual pre-release checklist

Doc 11 §6 matrix **plus**: legal docs unchanged or `LEGAL_VERSION` bumped
consciously · THIRD_PARTY_NOTICES current (dependency diff since last tag) ·
ATTRIBUTIONS.md regenerated · subset fonts regenerated · screenshots in
README still accurate.

## 7. Obtainium support (document in README)

Add app → GitHub source → `https://github.com/poli0981/quoteatlas` — the
stable `quoteatlas-v*-android-arm64.apk` pattern is picked up without custom
regex. This gives sideload users update notifications without us shipping a
store.

## 8. Data-only ("content") releases

Fast path for quote/holiday edits: normal PR → merge → `npm run release:prep
--patch` → tag. CI path filters keep these builds quick; release notes
lead with a "Content changes" section (locales touched, +added/−removed).

## 9. Rollback

Desktop: publish `v{x+1}` re-pinning known-good code (updater has no
downgrade; never delete a release used by `latest.json`). Web: Cloudflare
Pages instant rollback to a previous deployment. Android: users can
`adb install -r` an older APK only if `versionCode` allows — practical
rollback = fast-forward fix release; keep `versionCode` monotonic.
